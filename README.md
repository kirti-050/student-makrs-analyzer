# Student Marks Analyzer

## Overview

Student Marks Analyzer is a beginner-friendly NumPy project that analyzes student marks and generates useful insights.

The project demonstrates how NumPy can be used for numerical analysis, filtering data, and generating performance summaries.

## Features

* Calculate total marks
* Calculate average marks
* Find highest score
* Find lowest score
* Filter scores above a threshold
* Filter scores below a threshold
* Generate a performance summary

## Technologies Used

* Python
* NumPy
